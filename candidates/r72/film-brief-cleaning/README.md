# 影视简报样本清洗 Skill · r72

把原始影视剧舆情Excel整理为可供人工选材的离线观点工作台。本版新增：送审前跳过清理后长度不足的候选；收尾预留按实测调整为180秒；按剩余时间将补样包从最多10条逐级缩到1条，并优先补当前样本较少的组；最小批次也放不下时才收尾。保留全文明确AI稿排除、一次受控停滞恢复、有限编辑和显示清理。

解压后将整个film-brief-cleaning文件夹交给WorkBuddy加载。可直接输入：

> 按这个Skill处理【原始Excel目录】中【剧名】的本期数据，生成工作台。

从SKILL.md执行默认流程；需要Python 3.10+和requirements.txt中的openpyxl。只有一个主会话，使用当前模型的原生任务。默认入口为scripts/final_sample_review.py prepare --discover-viewpoints，不使用旧全量审查链。

总观点10—16组，正面至少10组、负面最多3组，每组最多10条。短评至少50字，文章至少70字，均最多360字；以清理后可见文字计数。材料不足必须报告缺口，不虚构观点或摘录。30分钟为运行上限；不得直连ydata.woa.com及其子域。
