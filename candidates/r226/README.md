# 影视观点聚类与写稿 Skill r226

- [WorkBuddy 使用说明](film-brief-cleaning/README.md)

解压后，在 WorkBuddy 中加载完整的 `film-brief-cleaning` 文件夹。提供本期 Excel 和作品名，先生成已审观点工作台，再选择人工选材或自动选材写稿。跨日对照时，在开始聚类前一并提交同一作品前几天已交付的 Word。

工作台和自动稿至少保留六个有证据的独立正面观点。图表中的“其他”收录少量未单列的真实负面意见，按样本计数，固定排在最后。

r226 的图表规则已用《尚公主》24 日的已审工作台验证。工作台到 Word 的完整实跑记录来自 r225。
