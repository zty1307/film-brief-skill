# 影视观点聚类与写稿 Skill r232

- [下载安装包](../../dist/film-brief-cleaning-r232.zip?raw=1)
- [WorkBuddy 使用说明](film-brief-cleaning/README.md)
- [完整 Skill 文件](film-brief-cleaning/)

解压后，在 WorkBuddy 中加载完整的 `film-brief-cleaning` 文件夹。提供本期 Excel 和作品名，先生成已审观点工作台，再选择人工选材或自动选材写稿。需要跨日对照时，在聚类前一并提供同一作品前几天已交付的 Word。

图表主要条目与最终正文观点一一对应。图左标签由对应段首句缩写，保留原评价动词和核心判断。图从上到下遵循最终正文段落顺序，“一是”对应第一条，“二是”对应第二条。非批评观点按实际样本量排序，批评在正文末段。“其他”固定在最后。脚本将批评和“其他”的图示配比分别限制在4%—6%和2%—4%，实际样本计数和占比保存在审计中。Word 自然分页，移除段前黑点对应的分页选项，文末附上正文实际引用样本的原文链接。第二部分标题通常列两个有代表性的正面判断，必要时列三个；标题按正文顺序，实际批评写在末尾。固定前缀之后常规38—42字，最多45字，标点及字母计入，空白不计。

本次标题长度规则以《尚公主》24 日的 DeepSeek V4.1 Flash 和 GLM 5.3 Flash 两份既有正文验证，保留原正文、图表和附录。
