## 在 WorkBuddy 使用

1. 解压两个安装包，分别加载完整的 `film-brief-cleaning` 和 `film-brief-propagation` 文件夹。首次运行按包内说明准备 Python 依赖。
2. 用本期原始舆情 Excel 和作品名运行第二部分。生成工作台后可人工勾选或自动选材。完成终审后保留 Word 和同一工作区的交付清单。需跨日对照时，在聚类开始前同时提供已交付的历史 Word。
3. 用本期热度表、微博热搜表及二期交付工作区运行第一部分。按交接说明完成话题、节点和情感审阅，再生成合稿 Word。已有独立情感统计时，可一并接入计数和样本范围。简报负面研判锁定在5%–10%（含两端），正文和图使用同一组比例。独立样本统计保留在核对记录。

交接已用《尚公主》同一期的实际文件联调，并通过了合稿、图表和样本链接校验。试用版报告仍按当期审核状态交付，待核话题和情感比例由分析师确认。

本版每期从完整统计曲线重新选点、查证节点原因。起始高点结合随后日期判断选词。情感段以人工稿固定句起头。
