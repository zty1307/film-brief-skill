# 节点写法参考

根据已审阅的6部电视剧、网络剧共9篇人工稿归纳。学习的是叙述层级、句子衔接和信息取舍，不把历史稿中的事件、演员、CP话题、热度或数字当成本期事实。必须先从本期证据选出因素，再参照下列写法；示例是占位句式，不是本期答案。

以“日期或传播阶段＋主要宣发或讨论情况＋热度变化”为主线。原因通常一两类，必要时可保留第三类，不凑数。先让读者看明白谁在宣传、什么内容引发讨论，再接符合曲线的热度判断。不需要另造一层“形成观看入口”“合力推高关注”等抽象解释，也不统一替换成同一个结尾。

短节点概括到“主创宣发”“剧情讨论”等层级即可；关键事件需要说明时，可保留一两项有证据的动作、演员名、物料名或时刻。删去后不影响理解的细节优先省略，不把活动逐项排成流水账，也不压成“开播／更新，热度走高”的空句。

## 先把句子写通

面向业务的节点段侧重有据的传播亮点。优先写主创宣发、主演互动或CP话题、剧情看点、演技及服化道等内容，也可写事实性动态和中性讨论。负面评价放在观点概述或风险研判中。只搜到负面材料时补找合适证据，仍不足则留缺项。夸赞须有实际观众反馈，不把官宣自动当成口碑，也不把投诉换成好评。

正文是一段传播情况概述，不是给每条检索材料配一句解释。把同类动作合并成自然的陈述，如“主创发布宣传内容”“网民讨论剧情走向”；保留动作或讨论对象即可，不必再塞入台词、营销卖点及活动经过。程度和范围按证据保留：一次发帖不能自动写成“持续宣发”，一篇评论不能写成“引发广泛争议”。

每个分句的主语和动作要清楚，前后保持同一叙述层级。两类因素可以平行陈述，不用“叠加”“作为卖点”“形成入口”强行连接。先自然成句，再从句中摘出审阅字段所需的短语；不要为了满足字段长度而拼接正文。

例如，下列均为虚构写法示意，不提供本期事实：

- 素材包含演员发布宣传海报和播前预告，可概括为“主演围绕开播发布宣传内容”，无需逐项讲海报文案和预告台词。
- 素材确有多条讨论人物关系与剧情发展的帖子，可概括为“人物关系与剧情走向引发网民讨论”，无需复述具体情节；讨论强度另据样本判断。
- 有据概括可连成“〔日期〕日，主演围绕开播发布宣传内容，带动剧集热度上升”。这里的推动关系也须有依据；若仅能证明宣传与热度变化同时出现，可写“〔日期〕日，主演围绕开播发布宣传内容，当日剧集热度上升”。

交稿前通读一次：不看来源的人能否直接理解每个分句；是否把零散细节硬连成原因；删除抽象解释后是否仍保留具体宣发或讨论。通顺和事实支持分别检查，不能用润色补足缺证，也不能因程序通过就认定文字合格。

## 按曲线情形选用热度句

热度词库只收人工稿实际用过的短句。程序先按当期曲线筛出适用候选，模型把其中一句原样放在正文结尾，前面的有据原因自行组织。表中的完整峰值句和展望句仅供审阅，程序负责补峰值和数值，后台成稿不自动加展望。

| 曲线情形 | 优先表达 | 使用条件 |
| --- | --- | --- |
| 明显升温、快速上升 | 拉动相关话题热度快速攀升；带动话题快速升温；全网讨论热度攀升；带动话题热度攀升；推高话题热度 | 上升须由趋势数据支持；“快速”需有明显增幅，不能用于微小波动 |
| 上升并达到周期最高点 | 推高话题热度，并于当日达到周期内传播峰值；全网讨论热度攀升，形成本轮传播峰值；带动热度达到周期内传播峰值；推动话题热度攀升至周期内峰值 | 峰值必须核验整个当期滚动序列；下文说明程序与模型的分工 |
| 前期高峰后再次明显走高 | 热度迎来二轮高峰；相关话题迎来周期内第二轮热度高峰 | 全曲线须能辨认前后两轮高峰及中间回落；不能把开播第二天、第二期报告或任意回升写成二轮高峰 |
| 相邻日期持续处于较高水平 | 相关话题热度保持高位运行；助推舆论热度保持高位运行；推动话题热度保持高位运行 | 结合整体曲线和相邻日期判断；起始日可用后一日核实是否持续较高 |
| 回落后重新上升 | 带动话题热度回升 | 曲线先回落再上升。采用词库表达，省去“有所”和重复的“当日剧集” |
| 首轮高峰或随后降温 | 致舆情出现首轮高峰；热度逐渐趋缓 | 首轮高峰须有前后趋势支持，起始高点按相邻日期另选表达。连续回落时可写热度逐渐趋缓 |
| 后续展望，可选 | 预计随着剧情推进热度有望继续走高 | 是预测，不是已经发生的走势；有充分研判依据且正文需要时才加，不按模板自动预测 |

### 连接词与主语

- 原因连接热度时，优先用“带动、推动、拉动、助推”；“推高话题热度”也可直接作结果分句。连接词须与句法匹配，例如“在主创持续宣发助推下，全网讨论热度攀升”，避免再接“助推”造成重复。
- 热度主语优先用“相关话题热度、话题热度、全网讨论热度、舆论热度”；指代清楚时可简写“热度”。这些是措辞习惯，不代表已取得全网讨论样本或证明全部传播来源。
- 峰值可写成“先变化、后峰值”的两段，如“拉动相关话题热度快速攀升，形成周期内传播峰值”；也可合为“带动热度达到周期内传播峰值”。一个节点采用一种，不重复报峰值。
- “持续引发热议／持续引发舆论讨论”属于前面的讨论情况，通常后接热度结果，例如“〔有据讨论对象〕等持续引发舆论讨论，推动话题热度保持高位运行”。不能拿它代替曲线判断；“持续”“热议”的范围与强度须有当期证据。

### 原因与热度衔接示意

以下只有写法，没有本期事件答案：

- “〔日期〕日，剧集上线播出后，在〔有据宣发动作〕助推下，全网讨论热度攀升。”
- “〔日期〕日，〔第一类事件〕，叠加〔第二类讨论〕，相关话题迎来周期内第二轮热度高峰。”
- “〔日期〕日，〔有据讨论对象〕等持续引发舆论讨论，推动话题热度保持高位运行。”
- “〔日期〕日，官方公布定档信息，〔有据的主创宣传情况〕，带动话题快速升温。”

不把开播必然写成攀升，不把第三期必然写成高位，不凭同日出现证明具体事件造成多少传播。没有足够讨论样本时，不照搬“层出不穷”“全网热议”“讨论转向”等范围、强度或转向判断。官方预告只能证明已预告。连续回落可用人工稿中的“热度逐渐趋缓”。当期曲线没有匹配的人工稿表达时，节点留待审阅。

## 峰值与数字

峰值可以提，前提是最终滚动趋势证明该节点达到整个统计周期最大值；由程序加“达到周期内传播峰值”，不让模型凭网页或旧稿认定。两轮高峰可作有据的趋势描述，不把局部高点写成整个周期最高点。上述含峰值的完整句式供学习衔接；当前接口仍由模型只写原因和非峰值热度句，程序核表后补峰值，不能在summary中复制完整峰值句而造成重复。

写到周期传播峰值就接“单日传播量约X条”。程序从同一滚动表取值并按万1位、亿2位显示。include_peak默认true，可按叙事需要设false。其余节点仅在include_daily_volume=true时补单日量。模型summary只填原因与热度判断。

正文直接写事件和走势，不写“据搜索”“该文涉及”“Excel确认”等过程说明。默认以一句为主，按下列字数预算概括，不为模仿样例增加预测、细节或修饰。

先按[node-selection.md](node-selection.md)看当期曲线选节点，再学习上述写法。局部峰值只是候选的一类；不解释所有小波动，不把末日固定为节点。

## 节点字数与压缩顺序

9篇非综艺人工稿的16个节点文本，中位数53字符；14个在30—80字符，最短29、最长113。《藏锋》第一节点统计包含前置趋势导语。含标点、数字、小数点、字母，各计1字符，空白不计。113字是《金色》首报的详细定档节点，不能拿这个少数长例作为日常输出长度目标。

- 完整日期节点通常30—80字，硬上限90字；日期、峰值、可选单日量都计入。两个节点通常合计80—140字，这是编辑目标，不为凑整段字数扩写。
- 模型summary通常25—55字，最多60字，为程序补日期、峰值和单日量留空间。程序补齐后再次检查90字上限；超长须重写原因概述，不自动截断。低于目标但已说明有据原因与走势的句子可以保留。
- 一节点以一句为主，把一两类有据推动因素与热度自然连起来。先合并同类宣传动作（直播、发博、互动、物料等），再删除无助理解的活动名、人物名单、台词和时刻；关键且必要的细节可以保留。不要只删连接词，留下更密集的活动清单。
- 压缩后仍须保留实际宣发动作或讨论对象，不删成“剧集开播，热度攀升”。不把两个近义宣发类别拆开凑数，不靠增加第二句热度或预测来补长度。
- 长度不合格沿用同模型现有一次短句修订；修订仍失败则保留待核，不增加无限重写，也不为合格长度牺牲事实依据。
