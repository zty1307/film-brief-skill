# 影视观点聚类与写稿 Skill r230

将本包解压，在 WorkBuddy 中加载完整的 `film-brief-cleaning` 文件夹。提供本期原始 Excel 或数据目录和作品名，Skill 会先交付已审的观点工作台。

## 选择写稿方式

工作台交付后，未指定方式时询问一次。当前 WorkBuddy 对话有原生提问工具时弹出单选题，其余情况在聊天里列出同样的两项，等用户回复。

- **我来选材料**。在工作台勾选观点和样本，点击“导出写稿选材”，把文件作为聊天附件发回。也可以发到已加载本 Skill 的新对话。
- **由你自动选材写稿**。模型从已审工作台选材，写报告第二部分“主要舆论观点”，通读审核后交付 Word。Word 包含观点分布图和实际引用样本的原文链接。

开始时已明确全自动、人工选材或只要工作台，直接按该指令执行。工作台最多 45 分钟，写稿和终审最多 15 分钟，分别计时。等用户选择及选材的时间不计入运行时间。

## 连续多天出报告

开始聚类前一并发来本期 Excel 和前几天同一作品已交付的 Word。Skill 会在聚类时对照旧观点，根据本期材料优先呈现有新证据、新判断的角度。持续受到关注的旧观点可以保留。

工作台至少有六组独立且有证据的正面观点。自动稿至少六个正面观点，人工稿按勾选的观点成文。工作台正面观点按已审去重样本数降序。成稿非批评段按本期实际计数降序，图表逐条承接正文顺序，批评4%—6%，“其他”2%—4%且严格最小。“其他”收少量未单列的已审负面意见，放在最后。附件链接按正文实际引用逐条对应。
