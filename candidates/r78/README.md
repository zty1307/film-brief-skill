# r78 候选：观点发现输入压缩与终审补选

本目录包含可交给 WorkBuddy 使用的 `film-brief-cleaning` 文件夹。运行方法、通用规则、三模型同表实跑结果与限制见 [Skill README](film-brief-cleaning/README.md) 和 [SKILL.md](film-brief-cleaning/SKILL.md)。候选代码基于 r77；未替换本机已安装的 Skill。

r78 在同一轮观点发现中优先保留已核实媒体和社交批评的独立召回线索，最多送 144 条摘录；其他粗分观点按组轮流占用名额。目标作品已在摘录里明确出现时省去重复上下文。终审保留原有逐字出处、长度、立场、目标作品及媒体近似重复检查，缩小有限编辑抽查包，并把已派未审的发布结果标为部分完成。规则不写死剧名、演员或具体期数，不新增原始数据。

《金色》5 份原始 Excel 的三模型独立实跑：DeepSeek 114 条、21 分 30 秒，有限编辑完成；GLM 95 条、27 分 42 秒，有限编辑因时间限制跳过；HY 127 条、23 分 38 秒，有限编辑完成。三轮最终均未剩已派未审包，所有 336 条展示摘录均核对到原始 Excel 单元格。GLM 的结果仅完成展示句初审，不能作为有限编辑也通过的证据。更多分组与来源数据见 Skill README。

这些成绩只来自《金色》本期原表；另一部《藏锋》已完成离线输入交叉检查，未作本版完整模型实跑。候选目录不含业务原表、工作台和模型日志。所有运行离线处理本地原表，不访问 `ydata.woa.com` 及其子域。
