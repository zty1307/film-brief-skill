# 影视简报样本清洗 Skill · r78 候选

把本期影视综艺舆情原始 Excel 处理为可人工选材的离线观点工作台。入口为 `scripts/final_sample_review.py prepare --discover-viewpoints`，需要 Python 3.10+ 和 `requirements.txt` 中的依赖。一个 WorkBuddy 主会话使用当前模型的原生审核任务，30 分钟为运行上限。

本候选版针对 r77 在《金色》实跑中 GLM、HY 样本数下降的问题：

- 观点发现输入最多 144 条，媒体和社交批评的独立召回优先保留，其余名额按粗组轮流分配；原句已有目标作品名时省去重复上下文，需要判定对象时仍保留。
- 末端有限编辑对普通正面组抽 1 条高风险样本，对客观、负面和高风险正面组最多抽 2 条；答卷路径不预建空文件，方便主窗口一次写出。
- 下一轮审核仍按观测耗时规划，编辑预留由 300 秒调整为 240 秒，收尾仍预留 180 秒。还有已派未审包时，结果明确标为 `FINAL_SELECTED_PARTIAL`。

保留 r77 的全表已核实主流媒体识别、社交平台具体批评召回、正面至少 10 组且不能拆近义观点、负面最多 3 组、正面及客观表演观点合计最多 2 组、逐字原文核验。新增规则均以来源类型和通用评价机制为依据，不写死剧名、角色、演员或某一期样本。模型只能审现有原表，不新增评论样本，不联网。不得访问 `ydata.woa.com` 及其子域。
