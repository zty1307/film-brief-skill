# 影视简报样本清洗 Skill · r74候选

把原始影视剧舆情Excel整理为可供人工选材的离线观点工作台。本候选版延续r73的表演观点收敛与负面来源优先，并在观点发现答卷中逐条核对现有微博、小红书代表摘录是否构成真实批评，再确定最多三组负面观点；不增加原始采样或模型轮次。r72的自适应补样、明确AI稿排除、有限编辑和显示清理继续保留。

解压后将整个film-brief-cleaning文件夹交给WorkBuddy加载。可直接输入：

> 按这个Skill处理【原始Excel目录】中【剧名】的本期数据，生成工作台。

从SKILL.md执行默认流程；需要Python 3.10+和requirements.txt中的openpyxl。只有一个主会话，使用当前模型的原生任务。默认入口为scripts/final_sample_review.py prepare --discover-viewpoints，不使用旧全量审查链。

总观点10—16组，正面至少10组、负面最多3组，其中正面/客观的表演观点合计最多2组；每组最多10条。短评至少50字，文章至少70字，均最多360字；以清理后可见文字计数。材料不足必须报告缺口，不虚构观点或摘录。30分钟为运行上限；不得直连ydata.woa.com及其子域。
